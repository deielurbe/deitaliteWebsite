Smart sales forecasting for MplusKASSA customers

We help hospitality businesses prepare for busy and quiet days, using their own sales data, weather, and local events.

What we want to build with MplusKASSA

An integration that allows MplusKASSA Q-line customers to easily share their sales data with deitalite. Once connected, they receive a daily sales forecast per dish, adjusted for weather and local events.

Fully automated, no more manual exports.

Data we need

Data Purpose
Sales per item (receipts + lines) Train prediction models
Products and articles Group forecasts by category
Historical data (12+ months) Learn seasonal patterns

We only request read-only access to sales data. No access to customer data, payments, or other sensitive information.

Technical specifications

  • Protocol: SOAP API with WSDL + Webhooks
  • Relevant endpoints: Financial data, Orders, Receipts, Products
  • Data sync: Initial backfill (12+ months) + monthly refresh for model retraining
  • SDK: PHP client library available

Reference: MplusKASSA Developer Portal

Security & compliance

  • Read-only access: we never modify data in MplusKASSA
  • GDPR-compliant: processing under explicit customer consent
  • Data minimization: only what's needed for forecasting
  • Revocable: customers can revoke access at any time
